# Personal Portfolio Website

## About the Project

This project is a personal portfolio website created for INFR3120 – Web and Scripting Programming. The website was created using HTML5 and CSS3 and contains four separate pages:

1. Home
2. About Me
3. Projects
4. Contact Me

The purpose of the website is to present information about me, my projects, and my contact information in a responsive portfolio website.

## Technologies Used

The website was created using:

* HTML5
* CSS3

The website uses semantic HTML elements including header, nav, article, section, and footer.

## Website Structure

The project contains four separate HTML pages:

* index.html – Home page
* about.html – About Me page
* projects.html – Projects page
* contact.html – Contact Me page

The website also contains separate CSS files for different screen sizes:

* full.css – Laptop/full sized screens
* tablet.css – Tablet screens
* phone.css – Smartphone screens

Images are stored in the images folder and the introductory video is stored in the video folder.

## Responsive Design

The website uses fluid design and media queries.

Three separate CSS files are used for different viewport sizes.

### Laptop / Full Size

The full.css file is used for screens that are 960px or wider.

### Tablet

The tablet.css file is used for screens between 481px and 960px.

### Smartphone

The phone.css file is used for screens that are 480px or smaller.

Using separate CSS files allows the layout and sizing of the website to change depending on the user's screen size.

The viewport meta tag is also used so that the website can display correctly on different devices.

## Gradients

Two types of CSS gradients were used in the website.

### Linear Gradient

A linear gradient is used in the header.

The gradient changes from one colour to another from top to bottom.

### Angled Linear Gradient

An angled linear gradient is used in the navigation area.

The gradient uses a 45 degree angle to create a diagonal colour transition.

These gradients were created using CSS3 linear-gradient properties.
